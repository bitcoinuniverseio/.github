# Code of Conduct

This code applies in every `bitcoinuniverseio` repository, issue, pull request, discussion, and review.

## Expected

- Be direct and technical. Argue about code, specifications, and evidence.
- Assume competence and good intent in others until shown otherwise.
- Accept review; the strongest argument wins, not the loudest account.
- Report real risk plainly, especially where user funds or assets are involved.

## Not accepted

- Harassment, insults, or discrimination of any kind.
- Publishing anyone's private information.
- Scams, phishing links, fake support, or impersonating maintainers. This ecosystem handles irreversible assets, so we treat these as attacks, not as rule-breaking.
- Sustained disruption of issues, reviews, or discussions.

## Enforcement

Maintainers may edit, lock, or remove content and restrict or ban accounts that break this code. Report conduct problems privately through GitHub's report feature or via private vulnerability reporting on this repository if the problem involves a security risk. Reports are handled confidentially.
