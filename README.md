# .github

Organization-wide defaults for `bitcoinuniverseio`.

| File | Purpose |
| --- | --- |
| [profile/README.md](profile/README.md) | The organization profile shown at [github.com/bitcoinuniverseio](https://github.com/bitcoinuniverseio) |
| [SECURITY.md](SECURITY.md) | Default vulnerability-reporting policy for every public repository |
| [SUPPORT.md](SUPPORT.md) | Default support routes |
| [CONTRIBUTING.md](CONTRIBUTING.md) | Shared contribution ground rules |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | Shared code of conduct |
| [.github/ISSUE_TEMPLATE/](.github/ISSUE_TEMPLATE/) | Default issue templates, including documentation issues and content requests |
| [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md) | Default pull-request template |
| [docs/conventions.md](docs/conventions.md) | Documentation conventions used across the organization |
| [docs/lifecycle.md](docs/lifecycle.md) | Public lifecycle and availability terminology |

A repository's own file of the same name overrides the default here.

Documentation home: [docs.bitcoinuniverse.io](https://docs.bitcoinuniverse.io). Platform source: [docs-platform](https://github.com/bitcoinuniverseio/docs-platform).
